# Gut Microbiome Data Analysis Project

This project analyzes gut and food microbiome datasets from:

1. Johnson et al. 2019
2. Carlino et al. 2024 (cFMD)

## Project Goals
- Profile microbiome abundance data
- Analyze dataset sparsity
- Calculate microbial feature prevalence
- Filter low-prevalence microbial taxa

## Datasets
- Paper 1: Human gut microbiome dataset
- Paper 2: Food microbiome dataset (cFMD)

## Methods
- Data loading and preprocessing
- Sparsity analysis
- Prevalence analysis
- Low-prevalence feature filtering

## Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook
