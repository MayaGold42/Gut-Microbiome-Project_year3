# Data Loading
## Setup
1. Clone both databases:
git clone https://github.com/knights-lab/dietstudy_analyses.git
git clone https://github.com/SegataLab/cFMD.git

2. Run paper1_data.py → generates:
   - microbiome.csv
   - sample_meta.csv
   - diet_raw.csv
   - diet_decay.csv
   - nutrition_totals.csv
   - microbiome_clr.csv
   - diet_fiber.csv
   - micro_avg_counts.csv
   - micro_avg_clr.csv
   - micro_avg_norm.csv

3. Run paper2_data.py → generates:
   - combined_datasets.csv
   - cfmd_metadata.csv
